# Week 8 <skewness & modality>

Data : the element in the multiset and which has certain context and is gathered in reality.

If data (3,4,5,-3.-5....) exists,

Statistically, we can find two things

skewness & modality.

Skewness : Mean of deviation^3 / sd^3 

modality : the number of local maximum at Probability Density Function.

-> unimodal(1), bimodal(2), multimodal(3+), uniform(0)

right skewed -> skewness > 0

left skewed -> skewness < 0

symmetrical -> skewness = 0
