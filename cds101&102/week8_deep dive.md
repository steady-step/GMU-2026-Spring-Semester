# Week 8 <skewness & modality>

If data (3,4,5,-3.-5....) exists,

mathematically, we can find two things

skewness & modality.

Skewness : Mean of deviation^3 / sd^3 

modality : local maximum at shape of probability distribution

We can indicate these two through histogram etc.

| v.s | Histogram | Bar graph   |
|--- | --- | --- |
| x-axis| number| categoricals|
|y-axis | number(count or percentage)|number(count)|
|interval between rectagnles |DNE| exists|

modality -> unimodal(1), bimodal(2), multimodal(3+), uniform(0)


right skewed -> skewenss > 0

left skewed -> skewenss < 0

symmetrical -> skwenss = 0

### Four steps for utilizing these two

1. making histogram etc controlling binwidth, bins.

2. If the dataset can be represeted to unimodal,

   there are mathematical properties.

   if right tail based on peak is longer than left one -> mean > median > mode

   left tail > right tail -> mode > median > mean

   left tail = right tail -> mode = medain = mean

   tail length -> the length between the end of right/left to peak although there are empty places in the middle.

3. there are also mathematical properties.

   right tail > left tail -> rigth skewed

   left > right -> left skewed

   right = left -> symmetrical

4. We can utlize this fact.

   the value of skewness can be compared with other datasets' one

   due to this formula, Skewness : Mean of deviation^3 / sd^3.

   Through this, unit disappeared. (ex : 35 m^3/ 7 m^3 = 5)

   Therefore, we can compare datasets each other.

   Also, we can select effective representative value analyzing histogram's shape.

   Unimodal + Right skewed(value : 2.5) -> Using median instead of mean as mean is distorted by extreme value.

   Unimodal + Right skewed(value : 0.5) -> Can use mean as tail length difference is not extreme.
