## Confusing points

    Although matlab's array is 1 or 2 dimension, it is just array. 

    But, if the dimension is under 3, matrix calculation is possible through operator.

    First, when using other operator except arithmetic operator, there are no problems.

    just consider array as array and use it.

    But, when using arithmetic operator, 

    +, - -> it can be used in both situation (element calculation and matrix one)

    .* etc. -> element calculation

    * -> matrix calculation

    Therefore, 

    dimension over 2 -> it can use +, - , element operator. (It can not use *)

    under 2 -> it can use +,-, *, / , element operator.
