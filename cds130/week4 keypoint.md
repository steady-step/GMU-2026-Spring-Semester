## Grammar

    for loop is a syntax for iterating some loops.

    the structure is like this.

    for variable = data (ex: n=1:3)

       contents

    end

    First, data is already created before entering for loop as array.

    And, the variable value is selected per each column.

    ex) data -> 1 2
                3 4  

        ->  first variable value :1 column, 2 rows array(1,3) -> Next -> 1 column, 2 rows array(2,4)
    
    end part -> move above again.

    for part -> change value

    Although for loop is ended, last variable value can be used in program.

    If statement -> conditional statement

    structure

    if statement

    contents

    end

    ex) if a>3

         disp("hello");

         end

    if statement -? checking its condition

    end -> end of the statement

    Also, there can not be 2 or more if statement in one end as equivalent statement.

    But, nested if is possible.

    if a>3

       if b>3

        ~~
        end

    end 

    But 2 end is necessary.

    Also, elseif and else are possible in one end.


    if-elseif-else

    if-elseif
