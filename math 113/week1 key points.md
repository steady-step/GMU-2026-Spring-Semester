## functions

    set : A collection of objects that can be clearly determined by a certain condition.

    function : The condition in relation from a one set to another set and elements of starting set are connected to only one element each of another set.
    
    domain : The starting set of function.
    
    codomain : The finishing set of function.
    
    range : the set of containing codomain's matched elements.
    
## Representation of function (4 ways)

    1. verbally (introduce function in words)
    
    2. numerically (represent function through table)
    
    3. visually (with graph)
    
    4. algebraically(such as y=x+3)

## Many kinds of functions

    1. even function : f(-x)= f(x), symmetric with respect to the y-axis.
    
    2. odd function : f(-x) = -f(x),symmetric with respect to the orgin.
    
    3. Polynomials : this type of function. constant is also polynomials.
    
       (Linear is one of the types of Polynomials, degree=1)
       
<img src="week1_file3.png" width="500">

    4. Power functions : y=x^a(a is real number), if a is fraction, it is root function. 
    
    5. Rational function : ratio of two polynomials.
    
    6. Algebraic functions: A function is only composed of addition, subtraction, multiplication, division, root, and rational  power.
      
    7. Trigonometric function : A function composed of Sin, Cos, tan etc.
    
    * Sin and Cos are range from -1 to 1, and the period is 2ㅠ.
     
    8. Exponential function : the function formed as y=a^x (a>0, and a is not 1)
    
    9. Logarithmic Function : the fuction formed as y=logbx (x>0, b>0, b is not 1)
