## Definition of function limit

  We can think limit value is a situation. But, it is false. Limit value is a constant. 
  
    When we define lim x->a f(x) = L, 

    first, we suppose countless Ls are limit value, and check whether it is real result.
       
      1. Suppose L is limit value.
      
      2. present an error value over 0.

      3. If we can find at least one positive variable r which means if changing interval x to (a-r,a)∪(a,a+r), 
      
         all f(x) is in (L-error,L+error), it is passed.

      4. If it is passed by any positive error, L is limit value.

      (Precondition : The set of available values for x should fully contain 
      
                      at least one open interval including a. (except possibly a itself))

    Also, when we define lim x-> infinity f(x) = L,

    first, we suppose countless Ls are limit value, and check whether it is real result.

    1. Suppose L is limit value.

    2. Present an error value over 0.

    3. If we can find at least one positive variable m which means if changing interval x to (m,infinity), 
      
       all f(x) is in (L-error,L+error), it is passed.

    4. If it is passed by any positive error, L is the real limit value.

    Precondition: Independent variable x's condition : +infinity
    
## Definition of infinity

 Infinity is not number, it is condition.
 
    We define positive infinity about variable like this.
    
      1. Present a positive number M.

      2. If there can exist larger variable value over M, it is passed.

      3. If it is passed on any positive number M, this variable condition is positive infinity.

    Also, when using ∞ in interval notation, ∞ doesn't contain complex meaning.

    It just means the interval goes on forever without an end.

    ex: (5,∞) ->{x|x>5}
    

## Limit laws

   when lim a and lim b exist,

      1. lim (a+b) = lim a + lim b
      
      2. lim (a-b) = lim a - lim b
      
      3. lim (a*b) = lim a * lim b
      
      4. lim (a/b) = lim a / lim b (lim b ≠ 0)
