# Week3 Confusing Point

## Limit law and Continious law

    Limit law : x range can be every range(3-,3+,3, infinity, - infinity), 
    
    if x range is same, and limit value exists, we can use this law for every fuctions. 

    If limit value is in denominator, the value should not be 0.

    Existence table (The limit value of....)

    Exist + Exist -> Exist

    Exist + Doesn't Exist -> Doesn't Exist

    Doesn't Exist + Doesn't Exist -> Unknown

    Continuous Law : x range can be every range except infinity, - infinity. (3-,3,3+)

    if function is in denomiantor, the value of function should not be 0.

    Continuous Table (The fuction is....)

    Continuous + Continuous = Continious

    Continuous + Discontinuous = Discontinious

    Discontinuous + Discontinuous = Unknown (Key point. We should check this when solving the continious range.)

    This laws are only applied for four basic operations.
