# Week3 Confusing Point

## Limit law and Continious law

    Limit law : x range can be every range(3-,3+,3, infinity, - infinity), 
    
    if x range is same, and limit value exists, we can use this law for every fuctions. 

    If limit value is in denominator, the value should not be 0.

    Existence table (The limit value of....)

    Exist + Exist -> Exist

    Exist + Doesn't Exist -> Doesn't Exist

    Doesn't Exist + Doesn't Exist -> Unknown

    Continious Law : x range can be every range except infinity, - infinity. (3-,3,3+)

    if fuction is in denomiantor, the value of fuction should not be 0.

    Continious Table (The fuction is....)

    Continious + Continious = Continious

    Continious + Discontinous = Discontinious

    Discontinious + Discontinious = Unknown (Key point. We should check this when solving the continious range.)

    This laws are only applied for four basic operations. 

## Composition of Fuction

    For calculating limit value of composition, we usually should track the limit. 

    Just think f(g(x)) as h(x) and track the limit.

    Usual limit law and Continious law are not applied and there are no values for checking the existence/continious table.

    We can just track and calculate the limit value.

    But, there is one special law. if g is continious at a, and f is continious at g(a) f(g(x)) is continious at a.

    So lim x->a f(g(x))=f(g(a)). We can use this law.
